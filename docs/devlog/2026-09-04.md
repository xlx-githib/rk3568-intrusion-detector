## 对主函数流程和部分知识的理解（看 main.cc 的收获）
- `fmt` = Format（数据排布）：
  - `NHWC`：按像素点存 `R1G1B1 R2G2B2 ...`，和 OpenCV Mat 一致，可直接喂图；
  - `NCHW`：按通道存 `R... G... B...`，同通道数据连续，NPU 连续读取效率更高。
- 主函数流程（RKNN 六连）：
  1. 读 `.rknn` 进内存 → `rknn_init` 建 NPU 会话；
  2. `rknn_query`：查输入/输出个数、维度数组、量化参数(scale/zp)；
  3. `while(1)` 每帧：`rknn_inputs_set` 喂 640×640 RGB → `rknn_run` 推理 → `rknn_outputs_get` 取 3 路输出；
  4. `post_process`（yolo.cc）：反量化→解码→NMS → 得到框；
  5. `rknn_outputs_release` 释放本帧；
  6. 结束 `rknn_destroy`。
- 结构体=「填参数表」：`rknn_input`(喂什么/数据指针)、`rknn_output`(want_float)、
  `rknn_tensor_attr`(查询结果 dims/zp/scale)；后处理结果 = `detect_result_group_t`(count+results[])。
- 为什么 Q8：模型 int8 量化后输出更快，`want_float=0` 拿原始 int8，用 scale/zp 自己反量化。
